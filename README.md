# Repository Master Thesis: 
## Macroeconomic and Bank-specific Drivers of Non Performing Loans and the EBA’s EU-wide Transparency Exercise: An Empirical Investigation.

- The objective of this paper is to analyze the impact of macroeconomic and bank-specific
 factors on Non-Performing Loans (NPL) in the EU-banking sector using an extensive, granular dataset on major European banks gathered by the European Banking Authority (EBA) in the context of the EU-wide Transparency Exercise for the period 2014-2019. 


- In the present repository are available the  different scripts and data used for  the empirical investigation.

- SAS: SAS software was used to prepare the data sets prior to the empirical analysis,
 including data collection, cleansing, transformation and storage. SAS is a statistical soft
ware suite developed by SAS Institute for data management and advanced analytics. This
 software is used for some tasks regarding data import, data transformation and relational
 data in order to set proper data structures.

 - Rstudio & R programming language: Final data sets are to be provided in .Rdata file
 format as the proper empirical analysis is performed in R. RStudio is an integrated devel
opment environment for R, a programming language for statistical computing and graph
ics. The generated code in a .rnw file format will be embedded in a LATEX document
 using knitr (an engine for dynamic report generation with R). R programming language
 is used in this thesis for graph/chart generation, descriptive statistics and the estimation
 and inference of parameters in the econometric models.

- TexMaker & PDF: This master’s thesis is presented in PDF format. The document was
 typed in LATEX (a document preparation system for high-quality typesetting) and compiled
 into PDF using PDFLatex. TexMaker is used as LATEX editor. TexMaker is a free, modern
 and cross-platform LATEX editor. This software was used parallel with knitr for the review,
 enhancement and refinement of LATEX syntax in the .tex files generated by knitr.
